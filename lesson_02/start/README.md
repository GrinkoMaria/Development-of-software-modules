# Отчёт по поездке

Программа считывает данные о тратах из списка и выводит итоговый отчёт.

## Как запустить

1. Создать окружение:
   `py -m venv .venv`
2. Активировать окружение:
   `.venv\Scripts\activate`
3. Установить зависимости:
   `pip install -r requirements.txt`
4. Запустить программу:
   `py trip.py`
