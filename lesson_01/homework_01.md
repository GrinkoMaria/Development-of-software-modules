Duolingo — это мобильное приложение для изучения иностранных языков в игровом формате с ежедневными уроками и системой мотивации. 

Действие 1:
	Упражнение на перевод. Когда пользователь выбирает вариант ответа, клиент отправляет на сервер идентификатор урока, выбранный ответ и ID пользователя. API проверяет корректность формата данных. Бизнес-логика сверяет ответ с эталонным значением из базы и проверяет, есть ли у пользователя жизни по правилам — если их нет, выполнение запрещается даже при правильном ответе. База данных обновляет запись о прогрессе пользователя. В ответе клиент получает статус правильности, обновленный счёт опыта и количество оставшихся жизней. 

Действие 2:
	Запуск челленджа. Клиент отправляет ID пользователя и ID выбранного соперника. Бизнес-логика применяет правило: челлендж можно создать, только если соперник существует и не участвует в активном соревновании на этой неделе. При соблюдении условий база создает новую запись о челлендже с датой старта и начальным счетом. В ответе клиент получает подтверждение, имена участников и дату окончания. 



Действие 3:
	Покупка внутриигровой валюты. Клиент отправляет ID пользователя, выбранный пакет и платежный токен. Бизнес-логика проверяет валидность токена через внешний платежный шлюз. После подтверждения платежа база в рамках одной транзакции создает запись о покупке и обновляет баланс пользователя. Клиент получает новый баланс и ссылку на чек.

Для действия 3:
При потере сети после списания денег, но до получения подтверждения, клиент показывает статус «в обработке»; при повторном запросе сервер проверяет уникальность платежа по токену и не списывает средства дважды. Двойное нажатие кнопки покупки блокируется сразу после первого клика, а сервер дополнительно проверяет временной интервал между запросами. При отправке пустого или невалидного токена API возвращает ошибку 400, база не обновляется, деньги не списываются.
